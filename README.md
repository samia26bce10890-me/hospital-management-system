# Hospital Management System

## Project Overview

This is a simple **Hospital Management System** developed in Python. The project uses functions, lists, dictionaries, loops, conditional statements, and user input to manage basic hospital-related information.

## Features

- Add hospital details
- Display hospital details
- Search for a hospital by name
- Add doctor details
- Display doctor details
- Add patient details
- Display patient details
- Book appointments
- Display appointment details
- Exit the program

## Information Stored

### Hospital
- Hospital name
- Location
- Contact number
- Number of beds
- Departments

### Doctor
- Doctor ID
- Doctor name
- Specialization
- Phone number
- Years of experience

### Patient
- Patient ID
- Patient name
- Age
- Gender
- Disease/problem
- Phone number

### Appointment
- Patient ID
- Doctor ID
- Appointment date
- Appointment time

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Conditional statements
- For loops
- User input

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python IDE.
4. Run the Python file:

```bash
python "pyth exp.py"
```

5. Select an option from the Hospital Management System menu.

## Menu

```text
1. Add Hospital
2. Display Hospitals
3. Search Hospital
4. Add Doctor
5. Display Doctors
6. Add Patient
7. Display Patients
8. Book Appointment
9. Display Appointments
10. Exit
```
