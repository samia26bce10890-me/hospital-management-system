# Hospital Management System

## 1. Problem Statement

Managing hospital information manually can be time-consuming and difficult to organize. Details about hospitals, doctors, patients, and appointments need to be stored and accessed efficiently.

The **Hospital Management System** is a Python-based application designed to provide a simple and organized way to manage basic hospital-related information. The system allows users to add and display hospital, doctor, and patient details, search for hospitals, and book and display appointments.

The project applies basic Python programming concepts such as **lists, dictionaries, functions, conditional statements, loops, and user input** to create a menu-driven management system.

## 2. Scope of the Project

The scope of this project includes the basic management of hospital-related information through a command-line interface.

The system provides the following capabilities:

* Adding hospital details.
* Displaying stored hospital details.
* Searching for a hospital by name.
* Adding doctor details.
* Displaying doctor details.
* Adding patient details.
* Displaying patient details.
* Booking appointments between patients and doctors.
* Displaying booked appointments.
* Providing a menu-driven interface for interacting with the system.

The current version stores information temporarily using Python lists and dictionaries during program execution. Permanent database or file-based storage is outside the scope of the current implementation.

## 3. Target Users

The intended users of this project are:

* **Hospital Staff:** To maintain basic hospital, doctor, patient, and appointment information.
* **Receptionists:** To manage patient details and appointments.
* **Administrators:** To view and manage basic hospital information.
* **Students/Learners:** To understand how Python programming concepts can be applied to a real-world management problem.
